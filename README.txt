MY PATH TO CHRIST — iPHONE/SAFARI

IMPORTANT:
Do not use the in-chat file preview to run index.html. The ChatGPT file preview can display an HTML file without running its JavaScript, which makes the buttons appear dead.

On iPhone:
1. Download this ZIP to the Files app.
2. Tap the ZIP once to unzip it.
3. Open the new My Path to Christ folder.
4. Press and hold index.html.
5. Choose Share, then Open in Safari (or choose Safari from the share sheet).
6. The app should run normally in Safari. The Path icon opens the section chooser, and the tutorial will appear on first visit.

The app is self-contained and does not need an internet connection for its local tracker features.
